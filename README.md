# Descripción

Este proyecto utiliza Spring Boot como framework principal para el desarrollo de aplicaciones Java. 

El objetivo es construir una aplicación robusta, segura y escalable que cumpla con los requisitos funcionales y de negocio. El sistema permitirá administrar información relacionada con clientes (personas naturales y empresas), cuentas bancarias, préstamos y transferencias.

La arquitectura del sistema está basada en el enfoque Domain-Driven Design (DDD) para una mejor organización del dominio del negocio.
